    Self-correcting figures & diagrams¶

    When an agent makes a figure, you shouldn't be the one who notices the legend covers a bar or the axis says "millions" when it means "thousands." The agent can see those things itself, if it's told to look. This page is about making "build it, check it, fix it, then show me" the default, so you stop spending time on mistakes the agent could have caught.

    The pattern¶

    A good figure process is a short loop, run before you ever see the result:

    1. Build the figure.
    2. Render it and actually look at it.
    3. Self-check for the obvious problems — a legend overlapping the data, unreadable or overlapping labels, a wrong unit, a mislabelled axis, a colour that disappears, a title that doesn't match the data.
    4. Fix what's wrong and repeat once or twice.
    5. Then show you the result.

    What reaches you is a checked draft, not a raw first attempt. You still judge the substance — but you're not doing the agent's proofreading.

    How it's set up today (soft, but reliable)¶

    The figure skills already work this way: real-data-figure and the TikZ/diagram skill instruct exactly this build → check → fix loop when you invoke them. That makes it a soft rule — an instruction the model follows when the skill runs (see how it works for the soft-vs-hard distinction).

    Turn it on everywhere (one line in your global config)¶

    The skills cover figures made through them. To make the self-check apply to any figure or diagram Claude builds for you — in any project, with or without a skill — add one instruction to your personal ~/.claude/CLAUDE.md (the global file Claude Code reads in every session). Paste this under a heading there:

    ## Figures & diagrams
When you create or edit any figure or diagram, do not show me the first
attempt. Render it, look for obvious problems (legend/label overlap,
unreadable text, wrong units, mislabelled or missing axes, a title that
doesn't match the data), fix them, and iterate up to 3 times. Only then
show me the result, and tell me briefly what you checked and changed.

    From then on, every figure request should get the loop, not just ones that go through a figure skill. It costs nothing and removes a whole category of back-and-forth.

    What's not yet automatic¶

    This is still a soft rule: Claude follows the instruction, but nothing forces the check to run. The hard version — a hook that fires automatically after any figure file is written, renders it, and reviews it without being asked — is on the roadmap. It needs care to work the same on Mac and Windows, so it's a deliberate, tested addition rather than something to rush into everyone's setup. Until then, the global rule above is the reliable way to get the behaviour everywhere.
