    New to Claude Code?¶

    If you've never used Claude Code, start here — it's a five-minute orientation, then pointers to the best existing guides (no need for us to re-write what Anthropic already documents well).

    What it is, in one line¶

    Claude Code is Anthropic's AI assistant that runs in your terminal (or as a desktop app / IDE extension) and can actually read, edit, and run files in your project — not just chat about them. If that distinction is new, read our short How Claude Code thinks — it explains "chat vs. a harness" and, importantly, that you approve every action; it's not autopilot.

    Get started (external, official)¶

    • Official quickstart — the canonical getting-started guide from Anthropic: https://code.claude.com/docs/en/quickstart. It covers signing in, your first session, and the basic commands. You need a terminal, a project folder, and a Claude subscription (Pro/Max/Team).
    • It also runs on the web, as a desktop app, and inside VS Code / JetBrains — the quickstart lists all of them.
