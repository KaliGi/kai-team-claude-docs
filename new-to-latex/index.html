    LaTeX¶

    Much of this kit assumes your paper is written in LaTeX, and several pages say "you can just compile it locally." If LaTeX is unfamiliar — or you've always used Word — here's what it is, why it's worth it (especially now, with AI), and how to set it up locally so you can produce a PDF without any online service.

    What LaTeX is¶

    LaTeX is a typesetting system for documents. Instead of formatting by hand as you type (Word), you write plain text with light markup — \section{...}, \cite{...}, an equation between $ … $ — and a compiler turns it into a polished PDF with consistent maths, references, and layout. The source is just text files (paper.tex, references.bib), which is what makes everything else in this kit work.

    Why LaTeX — especially now, with AI¶

    • Git and an AI assistant both work best on plain text. Because the source is text, git shows you a clean line-by-line history of every change, and Claude Code can read and edit the .tex directly — neither works well on Word's binary files.
    • The old downside is mostly gone. LaTeX's reputation for fiddly syntax was the main reason to avoid it. With an LLM writing and fixing the markup for you, that cost largely disappears — you describe what you want, it produces correct LaTeX.
    • Professional output for free. Maths, cross-references, bibliographies, and tables come out consistent and reproducible, the same every time.
    • Word is still fine if you prefer it — but you give up clean git diffs, smooth AI editing, and the Overleaf track-changes workflow. For a paper that several people and an agent will all edit, LaTeX pays off.

    Local setup — so you can compile without Overleaf¶

    You don't need Overleaf to use LaTeX; install a TeX distribution once and you can compile on your own machine, offline. Install the distribution for your OS (these are the standard installers — follow their own instructions, nothing to copy from here):

    • Windows: MiKTeX — installs missing packages on demand.
    • macOS: MacTeX.
    • Linux / cross-platform: TeX Live.

    An editor helps but isn't required: VS Code with the LaTeX Workshop extension, or TeXstudio — or just compile from the terminal. Once installed, building a PDF is one command in the paper folder:

    latexmk -pdf paper.tex

    LaTeX vs. Overleaf — use either¶

    Overleaf compiles in the browser (no local install) and adds track-changes review of prose. Local LaTeX is free, works offline, and integrates directly with git and Claude Code. Many people use both — local for day-to-day editing, Overleaf when a co-author wants to mark up the text. (Overleaf's track changes and git sync are paid-plan features the project owner sets up — see New to Overleaf?.) Which you need is part of choosing your setup.
