    Terminal 101 — for true beginners¶

    Why this page. A terminal is the one small prerequisite under everything else here — installs, git, and running a script all happen there. Ten minutes now removes the panic from every later step, so it's worth doing first if the terminal is unfamiliar.

    If you have never opened a terminal in your life, this page walks you through the absolute basics. After 10 minutes of reading and trying the commands, you'll be able to follow the main README.md install instructions without panic.

    If you've used cd and ls before, skip this page.

    What is a terminal?¶

    A terminal (also called "command line", "shell", "console") is a window where you type a command and press Enter, and the computer does it. Most modern apps hide the terminal behind buttons, but everything underneath is just commands. Researchers use terminals because some tools — like git, Claude Code, Stata's batch mode — are easier to drive by typing than by clicking.

    You'll only need a small handful of commands for the kai-team-claude install:

    • cd <folder> — change directory (move into a folder)
    • pwd — print working directory (where am I right now?)
    • ls (macOS/Linux) or dir (Windows) — list files in this folder
    • mkdir <name> — make a new folder
    • git clone <url> — download a GitHub repository
    • node --version, claude --version — check that something is installed

    How to open a terminal¶

    Windows¶

    1. Press the Windows key (or click the Start button), type "Terminal", press Enter.
    2. The app you want is called "Terminal" or "Windows Terminal".
    3. Don't open "Command Prompt" (cmd.exe) — it's older and some commands won't work the same.
    4. The window opens with a PowerShell prompt by default. That's what we'll use. You'll see something like: 
      PS C:\Users\YourName>
      The PS means PowerShell. The path after it is your current location.

    If "Terminal" doesn't exist on your Start menu, install it from the Microsoft Store (search "Windows Terminal") — it's free.

    macOS¶

    1. Press Cmd+Space to open Spotlight search.
    2. Type "Terminal", press Enter.
    3. A window opens with a prompt like: 
      yourname@mac ~ %
      The ~ means your home folder. The % is where you type.

    Linux¶

    You already know.

    Basic commands you'll need¶

    Where am I?¶

    pwd
    Prints your current folder, e.g., C:\Users\YourName or /Users/yourname.

    List what's in this folder¶

    macOS/Linux: 

    ls

    Windows PowerShell: 

    ls
    (Yes, ls works on PowerShell too — it's an alias for dir. Either works.)

    Move into a folder¶

    cd Documents
    Moves you into the Documents folder (must exist in your current location).

    cd ..
    Moves you up one level (out of the current folder).

    cd ~
    Moves you to your home folder. (~ is shorthand for the home folder on every OS.)

    cd ~/code
    Moves to the code folder inside your home folder. The slash direction (/ vs \) doesn't matter on PowerShell — both work.

    Make a new folder¶

    mkdir code
    Creates a folder called code inside the current folder.

    Run a command¶

    Just type the command and press Enter. Examples: - node --version — prints the installed Node.js version, or "command not found" if not installed - git --version — same for git - claude --version — same for Claude Code

    Copy-pasting commands safely¶

    Some commands in our install instructions are long (e.g., the claude mcp add zotero … line). Always paste them as a single line. Line breaks in the middle of a command break it.

    How to paste¶

    OS Shortcut Notes
    Windows PowerShell Right-click in the window, OR Ctrl+V Right-click pastes whatever is on your clipboard
    Windows Terminal Ctrl+Shift+V Standard paste shortcut
    macOS Terminal Cmd+V Standard paste
    Linux Terminal Ctrl+Shift+V (Plain Ctrl+V doesn't work in most terminals)

    Replacing placeholders¶

    When you see something like: 

    claude mcp add zotero -e ZOTERO_API_KEY=YOUR_KEY_HERE -e ZOTERO_LIBRARY_ID=YOUR_USER_ID …

    Don't paste it as-is. Replace YOUR_KEY_HERE with your actual API key, and YOUR_USER_ID with your actual numeric user ID. Then paste the whole line.

    If a command runs off the screen¶

    Long commands wrap to a new visual line in the terminal — that's just display, the command is still one line internally. Press Enter only at the very end.

    Reading errors¶

    Most errors look scary but are actually short. Read the last few lines — the rest is usually just a stack trace.

    Common errors and what they mean:

    Message Likely cause
    command not found: <name> The program isn't installed, OR it's installed but not on your PATH (close and reopen the terminal).
    permission denied / EACCES You need elevated privileges. On macOS/Linux, try the same command with sudo in front (it'll ask for your password).
    repository not found (during git clone) The URL is wrong, OR the repo is private and you don't have access.
    cannot find path / no such file or directory You're in the wrong folder. Run pwd to see where you are, then cd to where you should be.

    When you get stuck¶

    1. Read the error — usually it tells you exactly what's wrong.
    2. Copy the exact error text (highlight, right-click → copy).
    3. Email Kai the error text plus the README step number you were on. Don't try to fix it by clicking around — most stalls are 30-second fixes once we see the message.

    A quick sanity check¶

    Before starting the kai-team-claude install, try these in your terminal:

    pwd
cd ~
pwd
ls

    If those four commands work without error, you're ready. If any fails, ping Kai before going further.
