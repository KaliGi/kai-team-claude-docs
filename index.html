    kai-team-claude¶

    About this site — two URLs, two jobs

    You're reading the documentation here, on a public website (kaligi.github.io/kai-team-claude-docs). The toolkit itself is a separate, private GitHub repo — github.com/KaliGi/kai-team-claude — that you clone and install (ask Kai for an invite). This site is just the rendered docs, auto-published from that repo; you don't edit anything here. In short: you read here; you get the toolkit there. See Install the toolkit for the get step.

    What this is — two things, stacked. The base is a toolkit for Claude Code: AI helpers that make it good at academic-economics work — drafting and reviewing papers, building figures from real data, sourcing datasets, referee reports, talks. On top of it sits a tested collaboration workflow for several people writing one shared paper without stepping on each other. You can use the toolkit on its own; the collaboration workflow is the layer you add once you have co-authors.

    Where the friction is — worth reading once. The toolkit is low-friction: install it and it just helps, anywhere, even solo. Almost all of the rules that take getting used to come from the collaboration layer — git, clones, who-writes-what — not the helpers. So if something ever feels like overhead, it's almost always the collaboration half quietly earning its keep, preventing a bad day (lost edits, "which version is current?", drifting data copies).

    New to all of this?¶

    Already set up with Claude Code? Skip this section — go straight to Part 1 or Part 2 below, or jump to the reference.

    LLMs like Claude are genuinely good at the grunt work of research. There are two ways to use one:

    • A chat window (e.g. claude.ai) — you paste text, it answers. It can't see or change your files.
    • A harness — Claude Code (or Codex). A harness wraps the model so it can actually read and edit your files and run your code on your computer — with your approval at each step. This kit uses a harness. It's not magic and not autopilot: you approve what it does, and it can't run wild.

    Don't have Claude Code yet? → Install it (a one-time setup per laptop — budget about an hour for the full toolkit), then come back here and start with Part 1. And if words like clone, repo, or terminal are unfamiliar, the 10-minute primer and terminal in 10 minutes come first — no shame in starting there.

    Honest and flexible¶

    Claude is a convenience here, never a dependency: every collaboration task can be done by hand (the manual workflow), and each task page shows both the by-hand commands and the one-line Claude request. The collaboration workflow has a happy path (Claude Code + Dropbox = every safety rail on automatically) and graceful fallbacks (pure GitHub; or fully manual).
